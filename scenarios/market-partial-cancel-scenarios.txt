# MARKET PARTIAL-FILL CANCELLATION SCENARIOS (per MARKET_LEGEND.md)
# 11) If a market order cannot fully execute within slippage tolerance,
#     it fills what it can and cancels the remainder.

# --- PREP: Clean and modest funding ---
STRICT ON
U1 CA, U2 CA, U3 CA, U4 CA
U1 DEP 200, U2 DEP 200, U3 DEP 200, U4 DEP 200
SLEEP 250

# ============================================================
# 11a) MARKET BUY cannot fully execute within 1% slippage
# ============================================================

# Seed asks: best ask 2.50 (2 units), next 2.53 (10 units, +1.2% > 1%)
U2 LS 2.50 1 2, U3 LS 2.53 1 10
SLEEP 200
ASSERT ASK == 2.50
ASSERT DEPTH ASK 2.50 == 2
ASSERT DEPTH ASK 2.53 == 10

# Action: U1 MB 5 units with 1% slippage (100 bps) → can only fill 2 @ 2.50
U1 MB 1 5 100
SLEEP 300
ASSERT DEPTH ASK 2.50 == 0
ASSERT ASK == 2.53
ASSERT POSITION U1 LONG >= 2
# Ensure no resting buy from the leftover cancellation at the next level
ASSERT NO_ORDER U1 BUY 2.53

# Cleanup
U1 CA, U2 CA, U3 CA, U4 CA
SLEEP 200
ASSERT BOOK_EMPTY

# ============================================================
# 11b) MARKET SELL cannot fully execute within 1% slippage
# ============================================================

# Seed bids: best bid 2.40 (2 units), next 2.37 (10 units, -1.25% < -1%)
U1 LB 2.40 1 2, U3 LB 2.37 1 10
SLEEP 200
ASSERT BID == 2.40
ASSERT DEPTH BID 2.40 == 2
ASSERT DEPTH BID 2.37 == 10

# Action: U2 MS 5 units with 1% slippage (100 bps) → can only fill 2 @ 2.40
U2 MS 1 5 100
SLEEP 300
ASSERT DEPTH BID 2.40 == 0
ASSERT BID == 2.37
ASSERT POSITION U2 SHORT >= 2
# Ensure no resting sell from the leftover cancellation
ASSERT NO_ORDER U2 SELL 2.37
