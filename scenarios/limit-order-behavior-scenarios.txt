# LIMIT ORDER BEHAVIOR SCENARIOS
# Follows commands defined in MARKET_LEGEND.md

# --- PREP: Clean state and fund users (modest deposits) ---
STRICT ON
U1 CA, U2 CA, U3 CA, U4 CA
U1 DEP 200, U2 DEP 200, U3 DEP 200, U4 DEP 200

# ============================================================
# 1) LIMIT BUY ORDER BEHAVIOR
# ============================================================

# Setup asks (sell side liquidity): lowest ask = 2.50
U2 LS 2.50 1 10, U3 LS 2.55 1 10
ASSERT ASK == 2.50

# 1.a Buy should match: price above lowest ask (2.50)
U1 LB 2.60 1 5
ASSERT ASK >= 2.55

# 1.b Buy should rest: price below lowest ask (2.50)
U1 LB 2.40 1 5
ASSERT BID == 2.40
ASSERT ORDER U1 BUY 2.40

# 1.c No orders: clear book then buy should rest as a new order
U1 CA, U2 CA, U3 CA, U4 CA
ASSERT BOOK_EMPTY
U1 LB 2.30 1 3
ASSERT BID == 2.30
ASSERT ORDER U1 BUY 2.30

# ============================================================
# 2) LIMIT SELL ORDER BEHAVIOR
# ============================================================

# Setup bids (buy side liquidity): highest bid = 2.40
U1 LB 2.40 1 10, U4 LB 2.35 1 10
ASSERT BID == 2.40

# 2.a Sell should match: price below highest bid (2.40)
U2 LS 2.30 1 5
ASSERT BID >= 2.35

# 2.b Sell should rest: price above highest bid (2.40)
U2 LS 2.60 1 5
ASSERT ASK == 2.60
ASSERT ORDER U2 SELL 2.60

# 2.c No orders: clear book then sell should rest as a new order
U1 CA, U2 CA, U3 CA, U4 CA
ASSERT BOOK_EMPTY
U2 LS 2.55 1 3
ASSERT ASK == 2.55
ASSERT ORDER U2 SELL 2.55
